# CodePilot 自适应路由开发集校准（2026-08-19）

> 本报告只使用30条 `codepilot-dev.json`，用于 ROUTE-006 参数选择。它不是独立测试结果，不能作为泛化收益或正式简历指标。

## 方法与隔离

- 数据：仅 `.rag-eval/codepilot-dev.json`；调参 CLI 会在读取前拒绝其他文件名，未读取 `codepilot-test-v1.json`、冻结 Oracle或正式结果。
- 语料：当前工作树的本地 Chroma 索引，默认排除文档；Embedding 使用 D 盘已有 `all-MiniLM-L6-v2` 缓存，并强制离线模式。
- 每条查询只收集一次 Vector/BM25 Top-100，再按 QueryFeatures 和 Top-10 置信信号划分路由族，在内存中重放 Weighted RRF。
- 搜索空间：6组 BM25/Vector 权重、3个 `rrf_k`（10/30/60）、3个候选数（30/40/50），每个实际出现的路由族54组。
- 选择顺序：Recall@10、MRR@10、较小候选池、较小 `rrf_k`、声明顺序。没有使用 Rerank、网络或付费 API。

复现命令：

```powershell
$env:HF_HUB_OFFLINE='1'
$env:TRANSFORMERS_OFFLINE='1'
.\venv\Scripts\python.exe -m rag.retrieval_tuning `
  .rag-eval\codepilot-dev.json --project .
```

校准方案相对固定 RRF 的开发集绝对变化仅为 Recall@10 `+0.008333`、MRR@10 `+0.002051`。这是小样本内的参数选择结果，不代表统计显著或独立泛化收益。

## 结论与限制

- ROUTE-004 的1:1平衡规则对当前内部代码库过于激进；本轮改为 BM25 主导，仅在混合语言或明确排名分歧时有界提高 Vector 权重。
- 本轮没有接入 Retriever 默认路径；CPU 产品行为仍是固定 RRF，无法据此宣称400ms P95或自适应策略线上收益。
- 30条开发集由当前项目反推，路由族最少只有2条，过拟合风险高。参数从此冻结，下一步必须建立新独立验证集（ROUTE-007），不得回看 test-v1 调整。
